# Submission evidence checklist

After the deployed testnet demo is ready, add redacted assets here (or link to a private share) and update the root README with the public agent URL.

Required evidence:

1. Desktop product UI: sign-in, empty chat, semantic product result, exact-total approval, receipt.
2. Mobile responsive UI: at least 360px wide, including menu, chat input, store dialog, receipt, and activity list.
3. Testnet smart-contract evidence: TrustList/Agent Wallet contract links and a successful direct merchant payment on Stellar Explorer.
4. Monitoring/analytics setup: redacted Sentry issue dashboard and PostHog aggregate event dashboard, if enabled.
5. A short demo video: Google sign-in → wallet restore/funding → store OAuth → natural-language search → basket/quantity change → two approvals → merchant order and Stellar receipt.
6. Proof of 10+ wallet interactions: a redacted list of funding, policy, payment, or withdrawal interactions, with transaction links where applicable.
7. Basic user-feedback summary: anonymized participant count, tasks, key findings, and follow-up actions.

Never expose private keys, database URIs, JWTs, OAuth codes/tokens, delivery details, Google account data, or the Vercel token in screenshots or video.
